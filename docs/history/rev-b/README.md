# Earlier Rev B visual references

These first-party drawings and renderings show the earlier Rev B prototype. They were generated from simple component reference shapes and contain no exact A1M8 sensor mesh. The PNG files were re-encoded to remove build-path metadata.

They show superseded B02/B04 geometry and may depict the omitted B08 platform or unverified power placeholders. They are historical design illustrations, not a current print selection, fit proof, assembly instruction, or electrical plan. Use [current CAD status](../../../cad/README.md) and the [current build notes](../../CURRENT_BUILD.md) for present scope.
