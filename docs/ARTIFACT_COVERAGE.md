# Public artifact coverage

This edition retains selected reusable technical work. The exclusions below address identified privacy concerns and unresolved redistribution terms; the repository is not a blanket rights clearance for every referenced product or resource.

## Included

- Unaffected current and conditional printable parts, fit coupons and a repeatable STL audit
- Editable mechanical subset with a new schematic sensor proxy
- Historical first-party CAD generators, with missing inputs and limitations documented
- Public-edition beginner mechanical manual, editable authoring scripts and regenerated images
- Hardware architecture, power/stop and pin-map vector diagrams
- Sanitized hardware technical proposal and manufacturer resource register
- Reusable experimental v07.3 software source selected after a separate privacy review
- Privacy-edited v0.5 planning contracts and self-generated Rev B reference drawings/renderings, clearly marked as historical

## Omitted or replaced

- Superseded B02/B04 print files and B08 buck platform; current selection is documented instead
- Unvalidated battery restraints and power placeholders from the public editable scene
- Original full backups, shopping plans, purchase/order/delivery records and account history
- Original manual editions containing purchase context; a public edition replaces them
- Third-party sensor STL/display mesh, manufacturer drawings and bundled external binaries/model weights with unresolved redistribution scope
- The exact-reference-derived aperture profile, current C02 lid and T10 aperture coupon, including their editable meshes, pending reference-model redistribution clarification
- Potentially private environment layouts, screenshots/captures, runtime sessions, recovery records and machine-specific logs
- Duplicate older packaged runtimes, split downloads and patches superseded by the retained source revision

This is a curated technical publication, not a complete machine backup or a drop-in restoration bundle. See the software and CAD READMEs for external dependencies and missing-input limitations.
