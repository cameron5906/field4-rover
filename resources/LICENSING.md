# Licensing and third-party resources

No project-wide open-source or hardware reuse license has been selected for the original project materials. Public visibility does not by itself grant a general reuse license. A maintainer can add an explicit license after deciding the intended terms.

## External material

- Manufacturer manuals, product images, drawings and exact sensor CAD remain the property of their respective owners. This public edition links to manufacturer sources instead of redistributing their files where redistribution terms are unclear.
- The exact RPLIDAR A1M8 reference mesh and its decimated display cache are omitted. Public visualizations use an original simplified geometric proxy, clearly marked as illustrative.
- The 236-vertex aperture profile computed from that reference, the resulting C02 lid and T10 aperture coupon, and their editable meshes are also withheld pending redistribution clarification. This is a conservative publication boundary, not a legal conclusion about infringement or a change to the original private engineering design. Numeric mounting/clearance facts remain documented separately.
- Godot/Python runtimes, packaged dependencies and machine-learning model weights are not bundled. See the software README for upstream provenance and installation requirements.
- Source code that names a product or implements a matching interface does not transfer rights in that manufacturer's documentation or trademarks.

Primary hardware references are recorded in `manufacturer_sources.json`. The register preserves the source links used for the engineering proposal; it is not a claim that every linked document was revalidated for this public edition.
